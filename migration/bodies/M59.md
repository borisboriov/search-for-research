## Что сделать
Пройти сайт и записать замечания списком «где → сейчас → предлагаю». Смотреть как продакт:
понятно ли, честно ли, не отпугивает ли. ~20 минут, удобно с телефона.

- [ ] **Лендинг:** заголовок и подзаголовок, «Три шага», кнопка, три карточки-примера, подвал
- [ ] **Результаты:** обычный запрос («хочу заниматься нейросетями для текстов») — карточки, подписи «высокое / среднее / слабое совпадение»
- [ ] **Слабые совпадения:** запрос на границе базы («backend-разработка, микросервисы») — баннер «Совпадения слабые…»
- [ ] **Ничего не найдено:** запрос совсем не про науку («рецепт борща») — пустое состояние
- [ ] **Страница НР:** блок контактов, шаблон письма с кнопкой «Скопировать», ссылка «Это вы?»
- [ ] **404:** любая ерунда в адресе после `/supervisor/`
