# Карта `docs/` и репозитория

Что где лежит, как читать репозиторий, что генерируется и откуда нельзя брать
цифры. Раскладка — с 27.09.2026 (`docs/DECISIONS.md`, записи 27.09); это
единственная карта мест — праймер проекта Claude и `CLAUDE.md` папки документов
на неё ссылаются, а не повторяют.

`make docs-check` (`scripts/docs_check.py`, в CI) проверяет, что живые документы
согласованы: пути существуют, старых адресов нет, блок «Состояние» совпадает с
брифом, `meta.json` боевого индекса и `ApiSettings`; `make docs-check-live` — ещё и с
боевым `/api/health`.

Боевые цифры (каталог, индекс, пороги, качество с условиями применимости, открытая
итерация) живут в двух текстовых местах — блок «Состояние» в начале
`docs/DECISIONS.md` и бриф «Где мы сейчас» (`docs/product/brief.md`); плюс паспорт,
дек, Диск и `deploy/README.md`. Везде остальное — ссылка.

## Как читать репозиторий за 5 минут

1. Доска «SFR — задачи», фильтр `label:human` — что на Борисе, `label:decision` — что не решено.
2. `docs/DECISIONS.md` — блок «Состояние» (где мы сейчас) и сводка действующих решений; записи по датам — по мере надобности.
3. `docs/product/brief.md`, «Где мы сейчас» — то же для людей, плюс план и сроки семестра.
4. Последний отчёт итерации в `reports/` — §0 «Резюме для человека», DoD-чеклист, «Что не дотянуто».
5. Правила: `AGENTS.md` в корне репо (агент, issues, артефакты сессии; `CLAUDE.md` импортирует его), инструкции папки документов (паспорт, Диск, ПД).

`SESSIONS.md` заморожен 27.09.2026 (сессии 1–23 — история); новых записей нет:
что сделано — отчёт и PR, развилки и уроки — `DECISIONS.md`.

## Раскладка

```
docs/
  README.md            эта карта
  DECISIONS.md         ADR: блок «Состояние» + сводка действующих решений в начале, дальше — записи по датам
  SESSIONS.md          журнал сессий 1–23 (заморожен 27.09.2026 — история)
  PILOT_TEST_GUIDE.md  операционный гайд пилота
  reports/             отчёты итераций
  metrics/             JSON метрик — генерируются скриптами; больше не переносим (27.09)
  specs/               спеки закрытых итераций (история требований, не задание)
  product/             документы стартапа (бриф, спека MVP, история и Q&A, карта натяжек, гранты, ресерчи, план курса)
```

Спека **открытой** итерации лежит в корне репозитория, после закрытия уезжает в
`specs/`. Задачи — не здесь, а в GitHub Issues и на доске «SFR — задачи». Правки
паспорта — раздел «Правки паспорта» в отчёте итерации + issue `human` `docs`
(файлов-предложений `product/edits/` с 27.09.2026 нет).

## Откуда нельзя брать цифры

- **Цифры качества для паспорта и защиты** — только слепой судья:
  `reports/SFR5c_REPORT.md` §13.5 и §13.11, `metrics/sfr5c_deploy_metrics.json`;
  действующие значения с условиями — блок «Состояние» `DECISIONS.md`.
  Колонки «накопленная разметка» и все абсолютные Success@k отчётов до 26.09
  получены судьёй, который сам собирал каталог, — они для сравнения отчётов между
  собой, не для внешних документов (`DECISIONS.md` 26.09, канонический судья).
- **§4 и §6 `SFR5c_REPORT.md`** — измерение каталога **9 010**, а выложен 9 002
  (§13). Действующие числа — §13.
- **Пороги** принадлежат паре модель×индекс: действующие — в `ApiSettings`
  (`apps/api/src/sfr_api/settings.py`), `/health` и §13.4 `SFR5c_REPORT.md`; числа из
  отчётов SFR-2, SFR-5, SFR-5b — пороги своих индексов.
- **nDCG между отчётами несравним** (судейский пул разный); Success@k — только на
  неизменных наборах 22 и 24.
- **Калибровочные таблицы SFR-5, SFR-5b и OOD-блок §4 SFR-5c** считались на 19
  посторонних; действующий набор — 17 (`DECISIONS.md` 26.09). Воспроизводить их —
  с архивным набором (`make metrics-sfr5c`, `make ood19-sfr5c`).
- **Генерируемые отчёты** (`REPORT.md`, `SFR1_REPORT.md`, `SFR2_REPORT.md`)
  переписываются своими командами — править их руками бессмысленно.
- **Review-выборки в `data/eval/review/`** — рабочие выходы целей и CLI, каждый
  прогон их переписывает; доказательство — только файлы
  `packages/sfr-match/eval/` из таблицы «Доказательства» его README (#143).
- **Цифры-деньги** (рынок, стоимость хостинга) — не менять без решения Бориса
  (`product/market_stretch_map_2026-08-08.md`); `03_archive/` папки документов —
  не источник цифр.
