## Реализация и воспроизводимость

Фильтры строго `last_known_institutions.country_code:ru` и `country_code:ru`;
`per_page=100`, полные ответы без select, курсоры от `*` до явного null.
Метрики не ограничивают загрузку. Все исходные записи остаются в страницах,
в отдельном SQLite — последние версии по OpenAlex ID и флаг кандидата.
Текущие настройки отбора: works_count ≥ 10,
h-index ≥ 5, публикации в последние
3 календарных года включительно;
год 2026, свежесть по counts_by_year.

Данные: `/private/tmp/sfr-national-openalex-20261007/data/national-ru`.
Рабочая ветка: `codex/national-openalex-20261007`.
Команда продолжения и локальной проверки — [README ETL](../../packages/sfr-etl/README.md).
Журнал — collector.log, PID текущего процесса — collector.pid в каталоге данных.
Временный worktree нельзя удалять до передачи/сохранения этого реестра.

Бесплатный бюджет перед массовым сбором: $1/сутки, доступно $0,9996;
prepaid balance=0, сброс 08.10.2026 00:00 UTC (03:00 МСК).
Это фактический ответ /rate-limit существующего ключа, а не тариф из старых документов.
Каждая новая страница предваряется бесплатной проверкой остатка и цены list.
[Документация OpenAlex](https://help.openalex.org/api/authentication/) подтверждает
курсорный обход, per_page=100 и endpoint /rate-limit; цены взяты из живого ответа.

## Проверки и ограничения

Первый живой сбор прерван после 59 сохранённых страниц (5 900 авторов).
При повторном запуске цепь курсоров и SHA-256 проверены, сохранённые страницы
не запрашивались снова. Одна прерванная сетевая попытка имеет неизвестный исход:
сервер мог списать квоту до локального fsync. Exactly-once между API и диском
недостижим; восстановление всех сохранённых страниц проверено отдельно.

Связная цепь, manifest, SHA-256, равенство множества ID страниц и реестра,
отсутствие циклов/недостижимых страниц — проверены на измеренном срезе.
Конец организаций достигнут, конец авторов ещё нет. API меняется во время
обхода: min/max count фиксируется по каждой странице, повторы считаются отдельно.
Разница count и текущего реестра сейчас отражает **незавершённый обход**;
её нельзя приписывать изменению источника без финальных измерений.

Первые make lint/typecheck/test/docs-check прошли (393 теста, 8 skipped,
5 deselected, покрытие 93,62%). После дополнительных тестов проверки повторяются.
Локальная docs-check пропустила сверку с отсутствующим meta.json; рабочий индекс
не копировался и не менялся. Строгий аудит, независимое review-iteration,
актуальный CI и handoff-check ещё ожидаются. Они будут зафиксированы в PR.

Текущая БД, публикации, архивы измерений, dedup --apply, индекс, выкладка и
продуктовые документы не затрагивались. Правки паспорта не предлагаются:
принятых продуктовых чисел этот подготовительный этап пока не меняет.
