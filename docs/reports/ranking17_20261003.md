## Постановка и границы

Проверяется текущий FRIDA против одного дешёвого гибрида с BM25 на том же
каталоге. Это ограниченный эксперимент, а не завершение исторической SFR-7.
Production, исходные индекс/пороги, API, frontend и принятые продуктовые цифры
не меняются. Связь работы и полный промпт — [PR #185](https://github.com/borisboriov/search-for-research/pull/185),
исходная задача — [#17](https://github.com/borisboriov/search-for-research/issues/17).
Отсутствие улучшения — допустимый результат; гарантии 100% Success@5 нет.

Протокол [CRITERIA_RANKING17_20261003.md](../../packages/sfr-match/eval/CRITERIA_RANKING17_20261003.md)
зафиксирован коммитом `c5a4d7461757e59dbf5edf147a63934c62ed809f` до сравнения,
судейства и подбора. Подбор параметров не проводился: ровно одна альтернатива,
RRF dense top-50 + положительные BM25 top-50, равные веса, константа 60.
Тяжёлые модели, перевод/query expansion, новые источники/расширение каталога,
склейки и дообучение не входят в эксперимент.

## Диагностика до сравнения

Исторический [SFR5c_REPORT, §13.5 и §13.11](SFR5c_REPORT.md) показывает, что
гипотеза #17 «точно ранжирование, не данные» не установлена: прежний провал q10
изменялся при добавлении данных, а оценки q08/q29/q30 зависят от покрытия темы.
Это история, не новая разметка Astra. До сравнения получен новый baseline
top-50 для четырёх этих случаев (включая edge q28), отдельно от timed-прогонов.
Заметки и отпечаток диагностики сохранены в машинном снимке эксперимента.

| Запрос | Наблюдение | Вывод и предел |
|---|---|---|
| q08, NLP и GNN | В топе NLP/русские языковые исследования; полное сочетание обеих частей работами не подтверждено | Ограничение содержания/данных вероятно; retrieval/order не исключены. Простой лексический scan каталога не доказывает отсутствие профиля |
| q28, гражданское и договорное право | Конституционное право и шум в пятёрке; предметных работ в просмотренном top-50 не подтверждено | Недостаток найденных данных, а не доказанное отсутствие в каталоге |
| q29, хлебопечение | На ранге 8 A5006736805 с работой о производстве хлеба; top-5 содержит смежные темы и физику | Есть кандидат ниже пятёрки: возможный дефект порядка. Многотемность профиля и неразмеченный top-50 не позволяют объявить его grade 2 |
| q30, маркетинг в соцсетях | Маркетинг соседствует с политической коммуникацией; ниже есть B2B/потребительские работы | Порядок и неполное покрытие многочастного запроса могут влиять вместе |

Ни одному варианту не подставлялись известные релевантные люди. Для гибрида
кандидаты ограничены union dense50/lexical50: за ним качество неизвестно.
Неоценённый top-50 не объявляется нерелевантным и не даёт Recall@50.
Из 275 мест гибридных пятёрок 94 вне dense top-50 — существенное изменение
retrieval, которое требует проверки, а не аргумент в пользу улучшения.
[Проверка состава кандидатов](../metrics/ranking17_ranking_coverage.json)
также подтверждает: новый baseline совпадает с историческим top-5 того же
индекса на всех 30 golden, без использования исторических оценок в метриках.

## Метод сравнения и судейство

Полный uncached путь: штатная API validation/strip с явным k=5 → FRIDA encode
→ точный поиск → список результатов. Default API k=10 не изменён. HTTP,
сериализация/обогащение карточек, очередь и LRU не входят в локальную задержку.
У гибрида дополнительно BM25 и RRF. Новый backend не включён в API;
локальный инструмент запускает варианты явно. RRF score не cosine и не
используется для confidence/грейдов. Калибровка — отдельное будущее решение.

Три повтора каждого варианта в свежих процессах, один warmup, одинаковый порядок
всех 55 запросов; порядок вариантов B/H, H/B, B/H. Отдельный baseline top-50
получен после фиксации timed peak RSS, не подменяет timed поиск top-5.
Все повторы детерминированны, модель/индекс/validation совпадают, ошибок нет.
В первом прогоне v1 обнаружено некорректное представление неизвестного OOD
confidence гибрида как нуля. После проверки фикса `16cca82` оба варианта
полностью повторены на одной версии (v2); итоговые метрики используют v2.
Параметры, поиск и наборы не менялись, v1 сохранён как доказательство.
Сетевого сбора и новых API нет.

Общий слепой union top-5 содержит 386 пар, unique query_id/author_id, отсортирован
по этим полям. Нет варианта, rank, score, expect или старой оценки; видны запрос
и снимок профиля. Один sfr-judge, запущенный с gpt-6-astra/max, оценил его по
неизменной [рубрике](../../packages/sfr-match/eval/JUDGE_RUBRIC.md).
Конфигурация подтверждается фактическими native turn_context metadata в
[ranking17_agent_configuration.json](../metrics/ranking17_agent_configuration.json),
а не только полем judge. Реализация/основная сессия — Sol 6.1/medium.
API субагентов не предоставляет выбора именованного профиля: инструкции роли
переданы отдельному агенту, который прочитал конфигурацию/рубрику; модель и
effort явно заданы при spawn и проверены в фактических метаданных запуска.
Старая Fable-разметка не передавалась судье и не участвует в расчёте.

Каждая оценка связана через предусмотренный profile_fp (16 hex) и полный
profile_hash с **судимым** profile_text из пула. Это отображаемый текст Hit,
не обязательно исходное представление profile_text индекса. Неоценённые,
устаревшие и повторные пары блокируют расчёт; отсутствующие оценки не нули.
Отмеченные судьёй сомнения хранятся как alternate_grade/uncertainty.
Их min/max — чувствительность к этим развилкам, не доверительный интервал.
Новый межпрогонный разброс Astra не измерялся: исторические расхождения Fable
из SFR5c_REPORT нельзя переносить как его статистическую погрешность.
nDCG/общий corpus recall не заявляются: размечен только общий top-5 пул.

Пул v2 **побайтово совпадает** с v1, ранжирования и scores всех повторов также
идентичны; свежая Astra-разметка того же снимка не пересуживалась повторно.
Оценок 386, unique 386, распределение 2/1/0 — 98/100/188, спорных 23;
неоценённых/устаревших пар в итоговых пятёрках 0. Источник —
[judgments_ranking17_20261003.jsonl](../../packages/sfr-match/eval/judgments_ranking17_20261003.jsonl).

## Воспроизведение и сохранность

Запускать из корня собственной копии репозитория с зависимостями по uv.lock:

```bash
uv sync --locked --all-packages
make unhide
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
TOKENIZERS_PARALLELISM=false uv run --locked python scripts/ranking_experiment.py run \
  --index-dir /Users/boris/Projects/search-for-research/data/indexes_sfr5c/frida_clean \
  --queries packages/sfr-match/eval/queries.jsonl \
    packages/sfr-match/eval/ood_queries.jsonl \
    packages/sfr-match/eval/external_queries.jsonl \
    packages/sfr-match/eval/pilot_queries_ranking17_20261003.jsonl \
  --out-dir /absolute/new/output/directory
```

Нужны исходный read-only индекс и локальный HF cache указанной ревизии;
offline-режим не скачивает модель. Новый каталог обязателен: текущие результаты
не перезаписываются. Порядок судейства — eval README и роль sfr-judge. Автор
не заменяет независимую разметку. Для пересчёта сохранённых результатов:

```bash
uv run --locked python scripts/ranking_experiment.py measure \
  --out-dir /Users/boris/Projects/search-for-research/data/eval/ranking17_20261003/comparison-v2 \
  --judgments packages/sfr-match/eval/judgments_ranking17_20261003.jsonl \
  --out /absolute/new/metrics.json
```

Долговечное локальное хранилище —
