## Тексты #156 — приняты Борисом

- Высокое: «Высокое совпадение: по оценке поиска описание исследователя близко к твоему запросу.»
- Среднее: «Среднее совпадение: по оценке поиска описание исследователя частично близко к твоему запросу.»
- Слабое: «Слабое совпадение: по оценке поиска описание исследователя мало похоже на твой запрос.»
- Неожиданный вариант: «Неожиданный вариант: исследователь из смежной области, который может расширить твою тему.»
- Общая подсказка: «Поиск сравнивает твой запрос с описанием исследователя, составленным по публикациям OpenAlex. Степень совпадения помогает выбрать, какие профили изучить. Он не подтверждает готовность исследователя руководить твоей работой. Проверь темы и публикации в профиле.»
- Баннер: «Совпадения слабые: запрос мало похож на описания исследователей в каталоге. Попробуй уточнить запрос:»
- Советы: «Назови конкретную тему: например, анализ текстов вместо „машинное обучение“.» / «Добавь метод, который хочешь использовать: например, нейросети.» / «Укажи объект исследования: например, тексты соцсетей.»
- Действие: «Изменить запрос».
- Пустая выдача: «В текущем каталоге не нашлось уверенных совпадений с твоим запросом. Уточни тему, метод или объект исследования — или попробуй близкую область.»

На экране нет процентов, cosine score или выдуманной строки «совпало N из M».
Борис одобрил эти формулировки в продуктовом чате 02.10.2026. Одобрение Светы не заявляется.

## Ограничения проверок

- Проверки выполняются локально; production и Selectel не используются.
- На этом компьютере отдельные холодные запросы FRIDA заняли 12–17 секунд
  и превысили существующий клиентский таймаут. Финальный UI e2e-прогон использует
  прогретый существующий кэш реальных ответов. Ранжирование, пороги, таймаут и
  параметры API не подгонялись. Этот прогон не подтверждает холодную латентность.

  `test-results/.last-run.json`; аудит повторяется после завершения тестов.
- Для #161 Борис принял агентскую терминологическую проверку top-100 с источниками
  и четыре исправления. [Метод и границы](pilot-ui-topics-top100.md): внешняя сверка
  выборочная, научная экспертиза и человеческая вычитка всех 2 695 тем не заявляются.
- Полная редактура письма (#6), AI (#84) и перевод названий публикаций исключены.
