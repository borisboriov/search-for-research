Заморозка однократная: 1 случайный профиль каждого из12 вузов, исключены старые100,

Штатный SDK Pi1.1.0 заменяет CLI RPC, чьи настройки повторов могли бы изменить
глобальные settings. In-memory settings/session и явный system prompt исключают
домашние инструкции, skills и контекст репозитория из внешней модели. MCP/auth
используются штатно без передачи секретов. Адаптер разрешает только согласованные
подписочные endpoints; хост выдаёт разрешение перед каждым поиском/чтением.

Существующая Batch используется отдельной очередью на профиль; общий lock
ограничивает параллельность1. Остановка после403/429 долговременна, правила robots
проверяются до reader. Проверка robots входит в8 ресурсов, поэтому число полезных
страниц может быть меньше8. Полные ответы сохраняются до доставки модели,
цитаты проверяются исключительно по телу прочитанного reader, а не сниппетам.
Неизвестный исход LLM не перезапускается автоматически. Импорт готового вывода
возобновляется без новых обращений; исходное извлечение не перезаписывается.

## Контроль и ограничения

Предварительное подключение MCP выполнено без LLM и без поиска профилей;
оба инструмента обнаружены штатно. Это не измерение профиля. Старый smoke также
не входит в замеры нового пилота. Нативные проверяющие не используют веб;
контроль выполнения отвергает результаты с командами/MCP/web-инструментами.

Четыре пакета по3 в `paired-human/packets/`, слепые A/B; соответствие исполнителей
отдельно в `paired-human/unblinding/`. Для записи реального просмотра:

```sh
PYTHONPATH=scripts .venv/bin/python scripts/enrichment_pair_human.py \
  --root /Users/boris/Experiments/search-for-research/enrichment-pi12-20261009 \
  import-answers --manifest PATH/manifest.json --answers PATH/human-answers.json
```

Согласие двух агентов не эталон. До фактических ответов human_reviewed=0,
точность и полнота неизвестны. Цена Pi по каталогу не является списанием подписки;
денежный расход и дельта квоты null без штатного доказательства. Замечен отдельный
интерактивный Pi того же пользователя: общую дельту аккаунта нельзя целиком
приписывать эксперименту. Новый платный механизм не подключён.

Строгий аудит и handoff обязательны; известный блокер #189 не ослабляется и
не исправляется попутно. Ни контрольная точка, ни технические проверки не означают
человеческой приёмки или готовности к merge. Замеры реального запуска и итоговые
проверки будут добавлены после выполнения; текущий текст не утверждает их успех.

## Явная граница v1 → v1.1

Первый фактический запуск завершил3 сборщика, но все3 пакета остановились до
проверяющих:2 недословных цитаты,1 текстовое предисловие перед JSON. Сохранены
все исходные ответы и отдельный снимок замеров v1; повторных вызовов нет.
[Продолжение pi12-v1.1](../experiments/enrichment_pi12_v1_1.md) исправляет импорт,
привязку к реальному телу источника и долговременную остановку по замечанию
независимого ревью. Неверная исходная цитата не становится корректной цитатой:
она сохраняется отдельно, утверждение не меняется и не принимается автоматически.
Оба проверяющих получают одинаковый реальный исходный текст и исходные заявления.
Результаты сборщика необходимо разделять: первые3 v1, остальные9 v1.1;
их нельзя выдать за единый независимый тест после доработки.

Установленный Codex отклоняет переопределение built-in provider `openai`.
Глобальная конфигурация/провайдер не изменены, новый механизм не подключён.
Нативный координатор запускает каждый CLI ровно один раз; внутренние транспортные
повторы CLI не раскрыты и остаются неизвестными, а не нулём. MCP для этого
запуска отключается штатными локальными CLI overrides, веб disabled, timeout600s.
Pi SDK повторы отключены явно через in-memory settings. Подписочный расход null.

### Граница импорта v1.1 → v1.2

v1.1 не сделала новых LLM-вызовов:2 импорта остановились на точке в namespace,
1 на атоме без доказательства. Эти ошибки и исходная версия сохранены.
[pi12-v1.2](../experiments/enrichment_pi12_v1_2.md) сохраняет неподтверждённый атом
с evidence_refs=[] для проверки недостаточности, а не удаляет его. Непрочитанные
ссылки не попадают в доказательный пул. Полный тест переходов очереди с двумя
ответами/валидацией/пакетом/агрегатами выполнен без сети; это регрессия, не замер
профиля. Первые3 сборщика остаются v1, остальные9 используют фиксированную v1.2.
Парная проверка начинается только после этой фиксации. Человеческих ответов нет.
