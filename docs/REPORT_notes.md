## Разбор глазами: качество profile_text

Смотрел 5 примеров выше плюс выборочно ~15 профилей из `profiles.jsonl`.

**Что работает.** Профиль читается как осмысленная карточка учёного: имя, вуз,
h-index, 5 тематик и 4–7 работ с фрагментами аннотаций. По примерам сразу видно
специализацию — экономико-математическое моделирование (Шананин), комбинаторная
оптимизация (Goldengorin), NLP и детекция депрессии по соцсетям (Смирнов),
нейроинтерфейсы и мемристоры (Казанцев). Для embedding-поиска этого достаточно:
темы и аннотации дают плотный предметный сигнал.

**Проблемы, видимые глазами:**

1. **LaTeX/MathML-мусор в аннотациях физиков.** 197 работ содержат `\ensuremath`,
   `$…$` и подобное. В профиле это выглядит как
   `${e}^{+}{e}^{\ensuremath{-}}\ensuremath{\rightarrow}…` — токены-шум, которые
   съедают лимит символов и портят эмбеддинг.
2. **Аннотация = список авторов.** У мегаколлабораций (ATLAS/CMS/Belle) в поле
   аннотации иногда лежит `Author(s): Collaboration, The ATLAS; Aad, G; Abat, E; …`
   (3 работы в явном виде, но паттерн шире). Такой фрагмент не несёт научного смысла.
3. **Профиль ≠ личный вклад.** У участников мегаколлабораций (2 автора с
   works_count > 1000) профиль почти целиком состоит из статей коллаборации;
   тематика «размазана» по всей физике высоких энергий. Как научрук такой человек
   может специализироваться уже, чем показывает профиль.
4. **Смешение языков внутри профиля.** Русскоязычный автор + англоязычные работы —
   норма для источника (не переводим), но кросс-языковой поиск это должен уметь
   (проверка вынесена в мини-тест SFR-1).
5. **Тематики из OpenAlex иногда мимо.** У Шананина рядом с «Economic theories and
   models» стоят «Military Technology and Strategies» и «Linguistic, Cultural, and
   Literary Studies» — артефакт классификатора OpenAlex по журналам-сборникам.
6. **Обрезка на 1500 символах.** У 59 профилей из 261 последняя аннотация обрывается
   многоточием (режем по границе слова). Смысл не теряется, но для эмбеддинга это
   лишний хвост.

## Проблемы данных и что с ними делать в SFR-1

| Проблема | Масштаб на прогоне | Что делать в SFR-1 |
|---|---|---|
| Работ без abstract | 1700 из 6522 (26%) | Оставить: у 100% кандидатов есть ≥1 аннотация. Для «пустых» работ вклад в profile_text — только название |
| LaTeX/MathML в аннотациях | 197 работ | Чистить регуляркой перед сборкой profile_text (`\ensuremath`, `\text`, `$…$`, `\ifmmode`) |
| Аннотация = список авторов | ≥3 явных, паттерн шире | Эвристика-фильтр: доля `;`-разделённых токенов вида «Фамилия, И» > порога → аннотацию не использовать |
| Очень короткие аннотации (<100 симв.) | 45 работ | Использовать, но не в первую очередь: в отборе работ понижать приоритет |
| Однофамильцы / расщеплённые профили | 4 имени дублируются (`T. Aushev` 984 и 85 работ; `В. В. Иванов` — 3 профиля) | Это разные OpenAlex-профили: либо тёзки, либо расщепление одного человека. В SFR-1 — склейка кандидатов по ORCID + пересечению работ; сейчас не склеиваем (риск склеить тёзок) |
| Авторы без ORCID | 53 из 300 | Ограничивает дедупликацию; полагаться на ORCID как на единственный ключ нельзя |
| Одна работа у нескольких кандидатов | 351 работа (соавторство внутри МФТИ) | Ожидаемо и корректно (в БД составная уникальность). При эмбеддинге — понижать вес работ с большим числом соавторов |
| Мегаколлаборации | 2 кандидата (works_count > 1000) | Понижать вклад работ с сотнями соавторов в profile_text |
| Мусорные аффилиации | не выявлено | Фильтр `last_known_institutions.id` дал чистую выборку МФТИ |

Отдельно: **эвристика НР отсеяла 39 из 300 (13%)** — при сортировке по works_count
desc это ожидаемо мало, выборка смещена в сторону самых публикующихся. На «хвосте»
института (авторы с 10–30 работами) доля отсева будет заметно выше — пороги
(`supervisor_min_works`, `supervisor_min_h_index`, `supervisor_recent_years`) вынесены
в settings именно для этого.

### Что не дотянуто (не маскирую)

1. ~~**CI ни разу не выполнялся на GitHub.**~~ Было верно на момент сдачи SFR-0;
   **закрыто 29.08** — после пуша workflow отработал в Actions зелёным.

   в SFR-1: это влияет на качество эмбеддингов, и мерить эффект нужно вместе с

   по границе слова). Цифры холодного прогона в разделе «Прогон» — из первого,
