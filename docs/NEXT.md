# NEXT — план SFR-1 (embeddings)

Вход: `data/exports/profiles.jsonl` из SFR-0 (по одной строке на кандидата в НР:
`{id, name, institution, h_index, topics, profile_text, works}`).

## Цель SFR-1

Выбрать embedding-модель и собрать первый поисковый индекс: запрос студента
(свободный текст о научных интересах) → топ-K релевантных НР.

## 1. Мини-тест embedding-моделей (обязательный первый шаг)

**3 модели × 20 запросов** на реальных профилях SFR-0:

- Кандидаты моделей (мультиязычность ru/en обязательна — профили двуязычные):
  1. `intfloat/multilingual-e5-large` (сильный мультиязычный бейзлайн);
  2. `sentence-transformers/paraphrase-multilingual-mpnet-base-v2` (лёгкая, быстрая);
  3. `BAAI/bge-m3` (SOTA-класс, длинные тексты).
  Перед запуском свериться с актуальным MTEB (retrieval, ru) — список мог устареть.
- 20 тестовых запросов: сформулировать вручную по темам из топ-15 REPORT.md
  (10 ru + 10 en; от «квантовые вычисления» до узких формулировок).
- Протокол: embedding профилей → embedding запроса → cosine top-10;
  разметка релевантности вручную (по topics/works кандидата); метрики nDCG@10, Recall@10.
- Отдельно проверить: (а) чувствительность к языку запроса (ru-запрос должен
  находить en-профиль); (б) влияние длины profile_text (мегаколлаборационные
  профили из «шумных» абстрактов).

## 2. Инфраструктура SFR-1

- `packages/sfr-ml/` (или расширение sfr-etl): загрузка profiles.jsonl,
  батч-эмбеддинг, FAISS-индекс (IndexFlatIP для старта), сериализация в `data/index/`.
- CLI: `sfr embed build`, `sfr search "query" --top 10`.
- Отчёт мини-теста — `docs/EMBEDDINGS_EVAL.md` (таблица метрик, выбор модели, почему).

## 3. Данные (из проблем SFR-0 — см. REPORT.md)

- Фильтрация «абстрактов»-списков авторов у мегаколлабораций (эвристика: доля
  запятых/капитализированных токенов) перед эмбеддингом.
- Чистка LaTeX/MathML-артефактов в абстрактах физиков (`\ensuremath`, `$...$`).
- Взвешивание: понижать вклад мегаколлаборационных работ в profile_text.
- Рассмотреть второй вуз для проверки кросс-вузовости пайплайна (resolve уже готов).
