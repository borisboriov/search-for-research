### Фаза 1 — Референс-банк по слоям ✅ 11–12.09 (Claude; Борис — отсев)

Источники (открытые, без логина): Land-book, SiteInspire, One Page Love, SaaSFrame, Lapa Ninja — для структуры и визуала; Page Flows / UI Sources / Screenlane — паттерны; сайты живых продуктов — главный источник.

**Слой 1 — структура (для трёх страниц MVP).** 5 hero-блоков «одно поле — одно действие» (поисковые/AI-продукты); 5 блоков «как это работает» для сервисов-посредников; 5 страниц результатов поиска с карточками людей (hh.ru, Профи.ру, ПроДокторов, FindAPhD); 5 профилей эксперта с метриками и источником данных (Google Scholar, ORCID, Semantic Scholar, ResearchGate, ПроДокторов); 3 футера с указанием источника данных/лицензии.

**Слой 2 — UX-паттерны.** Для MVP: бейдж уверенности/совпадения, empty state поиска, фильтры ≤10 с «ещё», сохранённый запрос в строке. Для пилота: авторизация без пароля (magic link, VK ID / Яндекс ID); заявка НР со статусами — CRM-подобный список; отзывы о специалисте с модерацией и верификацией (ПроДокторов, Профи.ру); claim profile — «Это я» (Google Scholar, ПроДокторов «Это вы?»); публикация открытой позиции НР (FindAPhD project card).

**Слой 3 — визуальный язык.** 3–4 контрастные системы из живых продуктов: (а) тёплый серьёзный минимализм — близко к A; (б) плотная типографика с тёплым акцентом, «стартап для своих»; (в) академичный «редакционный» стиль с серифами и белым — под доверие «на годы»; (г) нейтральный «продуктовый Яндекс» как контрольный. Плюс 2–3 антиреференса — типовые вузовские страницы кафедр.

Каждый референс — карточка по формату гайда (источник → раздел → что полезно → не переносить → применение) + 6 вопросов + скриншот + ссылка. Выход: `design_references_2026-09.md` (57 карточек по 28 живым продуктам), скриншоты — папка документов `02_research/2026-09_дизайн_референсы/refs/`.

## 3. Правила отбора (из гайда + правила проекта)

- Не «красивый сайт вообще», а решение конкретного блока; у каждой карточки — что берём и куда.
- Живые продукты и конкуренты весят больше концептов с Dribbble/Behance.
- Ссылка + скриншот обязательно (страницы меняются).
- Референс не проходит, если ухудшает мобайл, скорость (БФТ ≤2 сек) или требует ручной вёрстки вне shadcn/ui.
- Не копировать один сайт: структура у одного, типографика у другого, показ продукта у третьего, форма у четвёртого.
- Открытость каталога — не пересматривать: антипаттерн ApplyIndex уже в решениях.
