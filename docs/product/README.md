# docs/product — продуктовые документы Search For Research

Текстовые документы стартапа (с 13.09.2026 живут здесь, а не в папке документов). Источник истины по цифрам — паспорт `Паспорт_Search_For_Research.xlsx` в папке документов и на Google Drive; здесь — производные и планы.

| Файл | Что это |
|---|---|
| `brief.md` | Бриф проекта: контекст + «Где мы сейчас» — входная точка любого треда (копия в проекте Claude) |
| `mvp_spec.md` | Спека MVP и план разработки (компоненты C1–C6, PoC → пилот, риски, юр. контур) |
| `brief_history_qa.md` | Хронология решений, риски рынка, Q&A-точки к защите |
| `market_stretch_map_2026-08-08.md` | Карта натяжек рынка — где расчёт стоит на верхних допущениях; цифры-деньги не менять без решения Бориса |
| `action_plan_2026-05-18.md` | План после тренировочного питча: 42 замечания, стратегические решения, Q&A |
| `qa_supplement_2026-08-08.md` | Q&A-дополнение к защите расхождений |
| `course_plan_NIR3-4.pdf` | План курса НИР 3–4 семестры (трек «Стартап») — источник milestones |
| `grants_tracker_2026-2027.md`, `fsi_grant_context.md` | Гранты и конкурсы; праймер по гранту ФСИ |
| `research/` | Deep research: дизайн (08.2026), юр. (08.2026), мировые аналоги, дизайн-направления и референс-банк (09.2026); скрины — в папке документов |
| `edits/` | Файлы-предложения правок паспорта `SFR_правка_<тема>_<дата>.md` от репо-агента; после внесения — в `edits/done/` |

Правила — `CLAUDE.md` в корне репо и `CLAUDE.md` папки документов.
