## Самое важное: цифра в паспорте станет ниже, а «было → стало» одним судьёй — выше

В паспорте сейчас стоит **Success@5 91,7 % / Success@1 75,0 %** на наборе 24
запросов. Эти числа ставил прежний судья — модель, которая в той же сессии
собирала каталог. С 26.09 цифры качества ставит **слепой судья**: отдельный
прогон субагента `sfr-judge` (Fable) по версионированной рубрике, пул без
прежних оценок, порядок пар не выдаёт запрос (`docs/DECISIONS.md` 26.09).
27.09 этот же судья по той же рубрике оценил и **прежний каталог** — поэтому
теперь есть честная пара:

| Набор | Паспорт сейчас (прежний судья, 5 538) | Слепой судья, 5 538 — **было** | Слепой судья, 9 002 — **стало** |
|---|---|---|---|
| Success@5, набор 24 | 91,7 % | 83,3 % | **87,5 %** |
| Success@1, набор 24 | 75,0 % | 62,5 % | **66,7 %** |
| Success@5 / @1, неизменный набор 22 | 90,9 % / 77,3 % | 90,9 % / 68,2 % | **95,5 % / 72,7 %** |
| edge-запросы (6), S@5 / S@1 | 83,3 % / 50,0 % | 83,3 % / 50,0 % | **83,3 % / 50,0 %** |

Как это читать:

- **Цифра в паспорте станет ниже (91,7 → 87,5 %) из-за смены судьи, а не
  каталога:** тот же строгий судья на прежнем каталоге дал бы 83,3 %.
- **Одним судьёй новый каталог не хуже ни на одном наборе** и лучше на один
  запрос из 24 по Success@5 и по Success@1. Один запрос — не статистически
  значимый рост; «+4 п. п.» без этой оговорки не произносить.
- **Единственный запрос, сменивший вердикт Success@5, закрыт данными:** `q10`
  («data science в физике») на прежнем каталоге не находил людей по теме, на
  новом в пятёрке Деркач и Ратников — лаборатория ВШЭ, которую квота срезала.
- **Разброс судьи на одинаковых входах не объясняет разницу:** на 87 парах,
  которые стоят в пятёрках обоих каталогов, два прогона разошлись в 7 (8,1 %,
  4 строже и 3 мягче), и ни одно расхождение не изменило вердикт Success@k.

Формулировка для защиты: «Мы сменили способ измерения на более строгий и
независимый: теперь оценки ставит отдельный слепой судья по рубрике, которая
лежит в git. По нему прежний каталог давал Success@5 83,3 %, нынешний — 87,5 %
на наборе 24 и 95,5 % на неизменном наборе 22. Цифра в паспорте стала ниже
прежней, потому что прежнюю ставил агент, собиравший данные; тем же строгим
судьёй новый каталог не хуже старого ни на одном наборе, а разница в один
запрос — это люди, которых раньше срезала квота».

## Оговорки к цифрам (обязательно к защите)

- **Абсолютные Success@k сравнимы только внутри одной разметки.** Слепой судья
  прогнан по обоим каталогам (27.09, #122): 83,3 → 87,5 % Success@5 на наборе
  24, 90,9 → 95,5 % на 22, Success@1 62,5 → 66,7 % и 68,2 → 72,7 %. Разница —
  **один запрос из 24** в каждой метрике, это не статистически значимый рост.
  Что можно сказать: «одним строгим судьёй новый каталог не хуже прежнего ни
  на одном наборе; единственный запрос, сменивший вердикт Success@5, закрыт
  людьми, которых срезала квота». Чего нельзя: «качество выросло на 4 п. п.»
  без оговорки про один запрос; сравнивать 87,5 % с прежними 91,7 % паспорта
  (разные судьи).
- **Человеческого судейства в проекте нет ни в одной итерации.** Единственный
  внешний контроль — выборка, которую читает человек:
  `packages/sfr-match/eval/judgments_for_review_deploy.md` (20 случайных пар),
  `judgments_borderline_deploy.md` и `judgments_borderline_base5538.md` (43 и
  50 пар, где судья сам колебался).
- **Два прогона одного судьи расходятся между собой.** Величина измерена:
  29,6 % на «решающих парах» SFR-5c (против накопленной разметки). Любая
  абсолютная цифра качества должна называться вместе с этим. Ориентир для
  разброса «один судья, одна рубрика, одинаковые входы» — 8,1 % (7 из 87 пар,
  общих для пятёрок двух каталогов, 4 строже и 3 мягче; ни одно расхождение не
  изменило вердикт Success@k). Это не измерение по плану: чистый разброс на
  решающих парах — issue #115.
- **Потолок ограничивает отбор из пула вуза, а не подпись на карточке.** Из
  1 800 отобранных под потолком МГУ часть подписана другим вузом (МГУ не первый
  в их списке аффилиаций). Правильная формулировка: «из пула МГУ взято 1 800
  сильнейших по областям», а не «в каталоге ровно 1 800 человек из МГУ».
- **9 002 — это 12 вузов, а не «вся Россия».** Потенциал источника (перепись
  17.09) — 110 721 автор при наших порогах, это верхняя граница: свежесть
  публикаций сервером не фильтруется.
- **Success@k сравним между отчётами только на неизменных наборах** (22 и 24);
  **nDCG между отчётами не сравним** — судейский пул разный.
- **Эталонный провал закрыт данными, а не ранжированием.** `q10` (data
  science в физике) у слепого судьи на прежнем каталоге провален, на новом
  закрыт людьми лаборатории ВШЭ (Деркач, Ратников), которых срезала квота. Это
  довод «расширение базы работает», а не «мы улучшили алгоритм». Второй
  эталонный запрос, `q07`, у слепого судьи провалом не был ни на одном
  каталоге — «закрыты оба» говорит только накопленная разметка.
- **Пороги** принадлежат паре модель×индекс. В паспорт идут те, что стоят в
  проде: с 26.09 — 0.33 / 0.40 / 0.49 для индекса на 9 002 (до того —
  0.32 / 0.40 / 0.47 для 5 538).
- **Дедупликация не идеальна:** 32 склейки, 267 профилей (2,97 %) с флагом
  «подозрение на чужую склейку OpenAlex», 163 группы тёзок оставлены как есть.
  Флаг студенту не показывается. В защите: «дубли и склейки OpenAlex —
  известное свойство источника, у нас есть правила и ручной контроль», а не
  «база чистая».
