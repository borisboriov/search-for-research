## Коротко: что даёт эксперимент и что с этим делать

1. **Каталог тех же 12 вузов без квоты — 12 119 профилей** (×2,19 к 5 538),
   у всех загружены публикации, 100 % `profile_text` в 300–1500 символах.
   Собран за одну ночь и 13 226 запросов OpenAlex (две дневные квоты
   бесплатного ключа). **В паспорт не вносить, пока не решено #90**: это
   размер возможного каталога, а не действующего.
2. **Перекос в МГУ:** без квоты МГУ — 35 % каталога (4 253 профиля), МГУ + СПбГУ
   + ВШЭ — 59 %. Формулировка «12 вузов» остаётся верной, «равномерно по вузам» —
   нет.
3. **Качество на наборах golden:** на неизменном наборе из 22 запросов Success@5 **90,9 % → 100 %**,
   Success@1 **77,3 % → 81,8 %**; на действующем наборе из 24 — **91,7 → 100 %** и
   **75,0 → 79,2 %**; мягкий Success@5 — 100 %. У 100 % запросов в топ-5 появился
   новый НР, у 96 % — с оценкой 2. Edge-запросы: Success@5 83 → 67 % (один запрос
   с опечатками). **Цифры экспериментального индекса, в паспорт — только после
   решения по #90 и проверки 20 оценок.**
4. **Пороги уверенности нового индекса:** 0.33 / 0.40 / 0.49 — действуют только для
   индекса без квоты; боевые 0.32 / 0.40 / 0.47 не меняются.
5. **Перепись пулов OpenAlex** (17.09, `docs/sfr5b_pool_census.json`): Россия
   при наших порогах — 110 721 автор (верхняя граница), вузы 61 413, НИИ
   62 428. Это цифра для формулировки «потенциал источника» в паспорте и для
   аргумента «50+ вузов» — её можно вносить **независимо от #90**, с оговоркой
   «верхняя граница: свежесть публикаций сервером не фильтруется, на 12 вузах
   её проходят 72 % пула».

## Оговорки к цифрам (обязательно к защите)

- **Каталог без квоты не в проде.** Все цифры «12 119» — про `data/sfr5b.db` и
  `data/indexes_sfr5b`; сервис отдаёт 5 538. До решения по #90 в защите
  формулировать: «эксперимент показал, что каталог можно удвоить за одну ночь;
  выбор пути расширения — открытое решение».
- **Метрики качества** считаны по golden set, написанному агентом (24 запроса
  in-domain), с оценками, которые ставил агент; человеком проверена только
  выборка. Внешний тест-сет по-прежнему из одного запроса. Success@k между
  отчётами сравним только на неизменных наборах (22 и 24), nDCG — нет.
- **Пороги** принадлежат паре модель×индекс: 0.32 / 0.40 / 0.47 — для боевого
  индекса на 5 538, 0.33 / 0.40 / 0.49 — для индекса на 12 119. В паспорт идут те,
  что стоят в проде.
- **Перепись пулов** — анонимные запросы 17.09; `group_by` отдаёт не больше 200
  групп, поэтому «топ-200 организаций» — не полный список.
