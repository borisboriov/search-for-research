# Граница продолжения Pi-пилота, pi12-v1.1

Первый запуск pi12-v1 на первых3 фиксированных ID завершил три сборщика, но не
подготовил ни одного допустимого пакета проверяющим: два исходных excerpt
содержали объединённые через многоточия части страницы, третий ответ добавил
текст перед JSON. Все исходные ответы/usage/материалы сохранены; LLM не повторяется.
Независимое предварительное ревью head670d17d выявило также недолговременную
остановку поиска при MCP-отказе429 внутри HTTP200 и при прерывании доставки HTTP
отказа хосту. Эта версия сохранена отдельно как незавершённая, а не успешная.

Изменение конвейера после просмотра первых результатов явно отделяется этой
версией. Исходный manifest, все12 ID и старые результаты100/v2/v3 неизменны.
Новый method-lock содержит SHA правил/кода и прежний sample SHA до следующего
обращения. Первые3 сборщика остаются v1; оставшиеся9 — v1.1. Общий бюджет всех
версий не обнуляется: 12 сборщиков максимум, никаких повторов;48 поисков/96 ресурсов.
Это смешанное продолжение, не единый независимый тест сборщика. Парная проверка
на всех12 начинается после фиксации v1.1 и использует одинаковую semantic-v3.

Те же утверждения сборщика (field/value/item_id) без исправления смысла связываются
с единственным успешно прочитанным первоисточником по URL. Если исходный excerpt
не является точной подстрокой, оригинальная цитата сохраняется отдельно как
ошибка извлечения; в ОБЩИЙ вход проверяющих помещается реальный текст страницы
(максимум первые20000 символов). Это не исправление ложного утверждения и не
его автоматическое подтверждение. При отсутствии единственного прочитанного
источника или тела пакет остаётся незавершённым. Исходные цитаты дополнительно
показаны человеку; неверные цитаты считаются отдельно от семантической точности,
которая без человека неизвестна. При усечении возможен пропуск; полнота не доказана.

Импорт выделяет один JSON из ответа с текстовым предисловием без нового вызова.
Несколько ответов JSON или неизвестная форма остаются ошибкой. Остановка доступа
восстанавливается из первичных HTTP-журналов и долговременных Batch-исходов,
включая поисковые запросы без домена; вспомогательное событие не единственный
источник истины. Повторный импорт после исправления не изменяет исходные ответы.

Инструкция сборщика [pi12-v1](enrichment_pi12.md) и рубрика
[semantic-v3](enrichment_verifier_v3.md) не переписываются. Изменены привязка
доказательств, импорт и восстановление остановки; исходные статусы пустых полей и
цитаты передаются в пакет. Human_reviewed=0 до фактических записей.
