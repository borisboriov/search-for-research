# Cache verifier benchmark, cache-verifier-v1

Ограниченное продолжение #193 / PR #194. Проверяется классификация одинаковых
сохранённых материалов двумя независимыми агентами, без нового сбора источников.
Это материал разработки из прежних 100; независимой оценки качества на нетронутых
профилях и проверки полноты источников нет. Старые roots не изменяются.

Фиксированы 12 профилей, 37 исходных атомов (до четырёх на профиль), 36 профильных
осей на проверяющего. Находки старого проверяющего исключены. Первые три:
Gohari A5015573260 (c3/c5/c7/c8), Kudryashov A5027597767 (c4/c5/c6/c7),
Belyaev A5100670875 (c2/c3/c5/c6). Остальные и точные ID находятся в константе
CASES скрипта `scripts/enrichment_verifier_inputs.py`; порядок оставшихся девяти
перемешивается Python Random(19319420261011). Vinogradov и Borisov имеют ноль
атомов; для них всё равно оцениваются identity/current_affiliation/activity.
Выбор сделан по типам исходных материалов, без старых модельных вердиктов.
Исходные value и excerpt не переписываются; некоторые value уже содержат
датированные пояснения прежнего сборщика, что ограничивает независимость теста.

Вход содержит только фиксированный профиль, выбранные атомы, объединение их
точных evidence_refs и профильных оснований. Из него исключены cohort, ID старых
агентов, пути, provenance, старые ответы/вердикты. Происхождение и SHA остаются
в приватном manifest. Общая инструкция semantic-v3, schema и JSON task одинаковы.
Pi SDK и native CLI имеют разные транспортные роли; одинаковые байты инструкции,
задачи и схемы не означают одинаковую внутреннюю реализацию поставщика.

Матрица: Pi zai/glm-5.3-flash/high и native gpt-6.1-sol/high; судья
native gpt-6-astra/xhigh, отдельный ephemeral CLI-контекст на пакет, без resume/fork.
Requested и эффективная Pi SDK-конфигурация отделены от неизвестного backend.
Native backend model/effort неизвестны. Только фактически раскрытый usage;
reasoning включён в output, cached не прибавляется повторно. Каталожная цена
SDK не является оплатой подписки. Прерванный поток имеет неизвестный полный usage.

Не более 12+12 содержательных заданий проверяющих и четырёх судей, 600 секунд
на задание, последовательность 1, автоматических LLM-повторов 0. Pi mode verify:
нет MCP extension и tools=[], фактический inventory обязан быть пустым. Native:
web disabled, read-only sandbox, command/MCP и связанные функции, а также hooks
выключаются только в изолированной команде; глобальные определения сохраняются,
trust не обходится. Native offline render показывает сообщения, но не отдельный
API inventory: наличие оставшихся инструментов (например apply_patch) неизвестно.
Любое фактическое item-событие инструмента, включая file_change и sleep, запрещает
принимать результат; разрешены только agent_message и reasoning.
До inference обязателен успешный offline `codex debug prompt-input`: никакие
домашние/проектные инструкции не допускаются. Отказ render останавливает запуск
до модели. Обе ветви используют один user JSON envelope task/output_json_schema.

Freeze сохраняет SHA кода, правил, инструкций, схем и всех общих входов до моделей.
Run по умолчанию выдаёт первые три; оставшиеся разрешает только checkpoint трёх
валидных независимых пар одинаковых входов и соблюдённых receipts/бюджетов.
Технический неуспех сохраняется и запрещает дальнейшие задания. Повторный run
читает завершённые пары либо импортирует уже полученные байты, без нового LLM.
Незавершённая, ошибочная и неизвестная попытка не перезапускается автоматически.

До четырёх слепых пакетов по три профиля: оба ответа A/B полностью, общие источники,
без модели, пути, seed, validation и provenance. Seed 19319420261012 и mapping
хранятся отдельно. Самоидентификация в ответе запрещает создание слепого пакета;
ответ не переписывается и дополнительное исправление моделью не запускается.
Судья оценивает каждый атом ОБОИХ ответов и три профильные оси: correct/incorrect/
insufficient_sources, error_types, severity, точные refs и русское основание.
Оба ответа могут быть правильны, ошибочны или недоказуемы. Корректное unknown
оценивается correct. Агентские оценки не являются человеческим эталоном.

CLI `scripts/enrichment_verifier_benchmark.py`: freeze --source-root OLD;
preflight; run --limit 3; checkpoint; run --limit 12; packets; judge; aggregate.
Везде обязателен --root NEW. HTML пакетов позволяет отдельный реальный просмотр
человеком через существующий paired-human контракт; автоматического human_reviewed
нет. Атомы и профильные оси имеют отдельные знаменатели, вывод о победителе без
судей не делается. Production, API/UI, индекс и продуктовые документы не меняются.
