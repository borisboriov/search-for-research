# Search For Research — дизайн-система v1 (для SFR-3)

**Версия:** v1 · 30.08.2026
**Решение:** для MVP выбрано направление **A «Научная свежесть»** (решение Бориса по итогам сравнения двух направлений на канвасе «Лендинг Search For Research»). Направление B сохранено в архиве канваса.
**Логотип:** знак «Совпадение» — две окружности с закрашенной общей зоной (из набора 6 знаков, сгенерированного в Claude Design по брифу). Метафора — мэтч студента и научрука, прямая связь с «% совпадения» в интерфейсе. Читается в 16px, работает в одном цвете. Файлы: `sfr-mark.svg`, `sfr-mark-mono.svg`, `sfr-favicon.svg`, `sfr-lockup.svg`.
**Обоснование выбора (для отчёта):** методология — `claude/Дизайн_ресерч_2026-08.md`. Кратко: два контрастных направления → сравнение по критериям (доверие для решения «на годы», отличие от казённых вузовских сайтов, консистентность с палитрой МФТИ в питч-деке, читаемость на мобайле) → выбор A; валидация на студентах отложена в TODO Светы.

## 2. Реализация: shadcn/ui + Tailwind

Почему: компоненты копируются в репо (агент правит их напрямую), a11y встроена, стиль задаётся токенами, MUI дал бы «гугловский» вид. Токены выше кладутся в `globals.css` как CSS-переменные и мапятся в `tailwind.config` (`colors.accent`, `fontFamily.display`, `borderRadius`). Компоненты, которые нужны SFR-3: `Button`, `Textarea`, `Card`, `Badge`, `Skeleton` (загрузка результатов), `Sheet` (фильтры на мобайле), `Tooltip` («по данным OpenAlex»). Иконки — `lucide-react` (stroke 2px, совпадает со стилем знака).

## 3. Правила экранов (из спеки MVP + дизайн-ресерча)

**`/` лендинг** — сделан (канвас). Одно действие: textarea + «Подобрать научрука». Плейсхолдер — реальный пример запроса. Секции: превью подборки → три шага → доверие (три цифры, честные) → CTA → футер с «Данные: OpenAlex (CC0)».

**`/results`** — следующий макет. Список (не сетка) карточек; в карточке: аватар-инициалы в `--accent-soft`, ФИО, вуз · должность, бейдж «NN%» в `--accent-soft`, темы одной строкой, метрики h-index / публикации в `--fg-subtle`. Над списком: запрос виден и редактируем, число найденных, фильтры ≤10 (вуз, h-index) — на мобайле в `Sheet`. Serendipity-слот — бейдж `--serendipity` с текстом «неожиданный вариант» и одной строкой пояснения. **Empty state при top-1 < 0.27:** «Уверенных совпадений нет» + подсказка переформулировать + 2–3 примера удачных запросов, кнопка «Изменить запрос» — не тупик.

**`/supervisor/:id`** — следующий макет. Иерархия: кто (ФИО, вуз, должность, знак совпадения с запросом) → чем занимается (темы, последние работы) → цифры с подписью «по данным OpenAlex» → действие «Показать email и шаблон письма» (PoC: copy-paste). Ссылка «Это я — редактировать/скрыть» внизу карточки (юр. контур).

**Везде:** mobile-first, ≤2 сек загрузка, ≤3 клика до результата; анимации умеренные — один reveal результатов (fade + 8px сдвиг, 200 мс), skeleton при ожидании ответа `/match`.
