## 2. Три правила направления

1. **Сериф — главный носитель.** Всё, что говорит от лица сервиса (H1, H2, счётчик), и имена научруков — Literata; гротеск — только для служебного текста ≤ 16px и для данных (темы, названия работ, метрики). Латинское имя набирается тем же серифом, что и русские заголовки, — смесь языков не бросается в глаза. *Проверка:* на `/results` имя — сериф 22px, всё под ним — гротеск.
2. **Один акцентный цвет, заливок им — две на экран.** Кнопка и один носитель смысла (бейдж грейда или полоса «совпало N из M»). Знак логотипа, точка ярлыка, ссылки — тот же цвет, но линией и текстом, не плашкой; цифры доверия — `--fg`, не акцентом. *Проверка:* на лендинге акцентом залиты только кнопки и бейдж в карточке; единственная крупная заливка — CTA-секция `--accent-deep`.
3. **Иллюстрация — только из интерфейса.** Картинок, градиентов, теней и декоративных панелей нет; иллюстрация раздела — три реальные карточки результата; в списке единственная «графика» — полоса совпадения тем с подписью-знаменателем. *Проверка:* `box-shadow` нигде; в превью лендинга — реальные профили из каталога, не образцы.

## 3. Правила экранов (что меняется относительно v1)

Тексты — как на живом сайте 11.09 («ты», «Научный руководитель под твою тему — за минуту», «Три шага до научрука», «Поиск научрука — 3–12 недель. Или минута.»). Числа — только из `/health`.

**`/` лендинг.** Герой по центру: ярлык-пилюля «● Кросс-вузовый подбор научных руководителей» (точка `--accent`, рамка `--border`, фон `--surface`) → H1 → подзаголовок → поисковый блок (без тени) с подписью «Бесплатно · без регистрации» и кнопкой со стрелкой. Раздел «Так выглядит подборка»: ярлык-пилюля, H2 по центру, **три реальные карточки** в компактном варианте (§4), подпись «Наукометрия — по данным открытого каталога OpenAlex». Раздел «Как это работает»: ярлык-пилюля вместо кружков 1/2/3 (S-06), H2 «Три шага до научрука», три карточки шагов с текстами v1. Цифры доверия — три, Literata 44px `--fg`, на `--bg-muted`. CTA-секция `--accent-deep` по центру. Футер без изменений.

**`/results`.** Строка запроса как в v1. Фильтры: чип **«Организация: все»** вместо «Вуз: все» (см. `docs/DECISIONS.md` 12.09, «вуз» в интерфейсе), «h-index: любой», «Должность: любая» (скрыт до C6), справа сортировка «По совпадению» активным чипом. Счётчик — **заголовком** Literata: «Нашли N научруков из M организаций» + подпись `--fg-subtle` «Отсортировано по совпадению с запросом · темы и работы — по публикациям OpenAlex» (S-09). Список — колонка 920px по центру (S-08). Карточка — §4. Под списком: «Показать ещё N научруков» и строка «Наукометрия — по данным открытого каталога OpenAlex. Как работает подбор». Скелетон — с пределом 10 с и состоянием ошибки с кнопкой «Повторить» (P-24). Пустое состояние — как в v1, токены новые.

**`/supervisor/:id`.** Иерархия v1; процент убран (решение 11.09), грейд словом; в блоке «Чем занимается» — строка «Темы посчитаны по публикациям в OpenAlex; научный руководитель их не подтверждал» (P-09); над метриками — плашка «Данные: OpenAlex · обновлено <дата индекса из /health>» вместо мелкой подписи (P-08). Список работ — строками, длинные названия целиком.

**Везде:** mobile-first, ≤2 сек, один reveal результатов (fade + 8px, 200 мс), skeleton при ожидании `/match`.

## 4. Карточка результата (SupervisorCard v2)

Десктоп: аватар-инициалы 44px (`--accent-soft`/`--accent`; у serendipity — тёплая пара) слева; справа колонка: строка «имя (Literata 22) — бейдж грейда» → **ярус фактов** с иконками lucide (`building-2` организация · `user` должность, если есть · `bar-chart-3` h-index N) → **строка «почему подошёл»** (см. ниже) → **ярус тем**: серые пилюли `--bg-muted`/`--fg-muted` 12.5px, переносятся, не обрезаются (P-06) → «<год> · <название последней работы>», обрезка ~64 знаков + ссылка «раскрыть» (Collapsible, P-15) → кнопка «Открыть профиль» secondary внизу справа. Мобайл (390): аватар 40 + имя в одной строке, бейдж под ними, дальше те же ярусы, кнопки нет — вся карточка ссылка. Serendipity: рамка `--serendipity`, бейдж «неожиданный вариант», вместо «почему подошёл» — «Почему в подборке: …».

**Строка «почему подошёл» и полоса совпадения (P-18):** полоса из M сегментов, N залиты `--accent`, подпись «Совпало N из M тем запроса · по публикациям OpenAlex»; ниже «K публикаций по теме с <год>». Рендерится **только когда `/match` отдаёт поля `matched_topics` / `query_topics` / `works_on_topic`** — их даёт итерация ранжирования (SFR-7); до неё компонент скрыт, карточка без него валидна. Ничего не вычислять на фронте и не подменять косинусом.

Компактный вариант (превью лендинга, три в ряд): мобильная раскладка карточки без кнопки, вся карточка — ссылка на профиль.

## 5. Реализация

Tailwind v4: токены — в `app/globals.css` (`@theme`), шрифтовые переменные — `@theme inline` от `next/font` (`--font-literata`, `--font-plex`); `--font-display` → Literata, `--font-sans` → Plex. Компоненты shadcn без модификации: Button, Textarea, Card, Badge, Skeleton, Sheet, Tooltip, Collapsible (новый), Progress не нужен — полоса из сегментов проще. Значения не округлять к сетке и не заменять шрифты.
