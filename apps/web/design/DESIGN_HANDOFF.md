# SFR — передача дизайна для планирования и разработки фронта (SFR-3)

**Дата:** 30.08.2026 (v2, полный комплект) · **От:** дизайн-тред (Борис + Claude) · **Кому:** агент планирования MVP / автор `SPEC_SFR-3.md`

## Статус: дизайн MVP готов — все три страницы, десктоп и мобайл

Зафиксировано решением Бориса:

- **Визуальное направление** — одно, «Научная свежесть»: светлый тёплый фон, индиго-акцент, серифные заголовки Spectral + текст Golos Text, карточки с 1px границей и радиусом 14px. Альтернатива («Смелый кампус») рассмотрена и отклонена — в архиве, не учитывать.
- **Логотип** — знак «Совпадение» (две окружности с общей закрашенной зоной) + словесная часть «Search for Research» (Spectral 500). SVG в `logo/`: знак, монохром, фавикон, лок-ап. Класть в `public/`.
- **Токены** — полный набор в `DESIGN_SYSTEM.md` §1 (цвета, типографика, радиусы, отступы, кнопки). Источник истины для `globals.css` и `tailwind.config`.
- **Стек UI** — shadcn/ui + Tailwind поверх Next.js; компоненты: Button, Textarea, Card, Badge, Skeleton, Sheet (фильтры на мобайле), Tooltip; иконки lucide-react (stroke 2px).

## Компоненты, которые следуют из макетов

- `Logo` (знак + словесная часть; вариант mono для футера).
- `SearchBox` — textarea с плейсхолдером-примером, CTA «Подобрать научрука», подпись «Бесплатно · без регистрации».
- `QueryBar` — строка текущего запроса + «Изменить запрос» (на мобайле — иконка карандаша, текст обрезается многоточием).
- `FilterChip` (обычный / активный) и `FiltersSheet` для мобайла; фильтры MVP: вуз, h-index, должность; сортировка по совпадению.
- `SupervisorCard` — состояния: обычный (бейдж «NN%»), serendipity (бейдж `--serendipity` «неожиданный вариант», аватар в тёплой палитре), skeleton. Десктоп: горизонтальная карточка с кнопкой «Открыть профиль» справа; мобайл: вертикальная, вся карточка кликабельна.
- `MatchBadge` — «NN%» или «неожиданный вариант».
- `EmptyResults` — по `results-empty`.
- `SupervisorHeader`, `MetricsCard` (с Tooltip «по данным OpenAlex»), `WorksList`, `ContactCard` (PoC: показать email + шаблон, копирование; отправка из сервиса — пилот), `ClaimProfileLink`.

## Правила поведения

- Один reveal списка результатов (fade + сдвиг 8px, 200 мс); skeleton-карточки на время запроса к `/match`. Других анимаций нет.
- Тап-таргеты ≥44px; кнопки primary 14px 26px, высота ≥44.
- Порог отсечки 0.27 приходит с бэкенда (`/match`); фронт рисует `EmptyResults`, если бэкенд вернул пустой список/флаг «нет уверенных совпадений».
- Serendipity-слот — как отдаёт бэкенд (позиция и флаг); фронт только рисует бейдж и пояснение.
- Тёмная тема — не в MVP. Брейкпоинты стандартные Tailwind; макеты даны для 1440 и 390, промежуточные ширины — по здравому смыслу (сетка 3 → 1 колонки, две колонки профиля → одна на `< lg`).

## Что вносить в SPEC_SFR-3

1. Скаффолд Next.js + Tailwind + shadcn/ui; токены §1 → `globals.css` → `tailwind.config`; шрифты через `next/font/google` (Spectral 500/600, Golos Text 400/500/600).
2. Лого и фавикон из `logo/` в `public/`; компонент `Logo`.
3. Компоненты из списка выше; `SupervisorCard` переиспользуется на `/` (превью) и `/results`.
4. Страницы `/`, `/results`, `/supervisor/:id` по макетам — верстать по `.dc.html`, сверять с `.png`; мобайл — по `-mobile` макетам.
5. Состояния: skeleton, empty, ошибка сети (макета нет — сделать в стиле `results-empty`: заголовок, одна фраза, кнопка «Повторить»).

## Как читать `.dc.html`

Всё внутри `<x-dc>…</x-dc>`, стили инлайн, шрифты подключены `<link>` в `<helmet>`. Строку `<script src="./support.js">` игнорировать (служебная для редактора). Значения (px, hex, gap, radius) переносить как есть — не округлять к сетке 4/8 и не менять шрифты на Inter/Roboto.
