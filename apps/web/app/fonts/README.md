# Шрифты сайта (направление B)

| Файл | Гарнитура | Оси | Лицензия |
|---|---|---|---|
| `Literata.woff2` | Literata 3.103 (TypeTogether) | `wght` 400–900, `opsz` зафиксирован на 14 | SIL OFL 1.1 — `Literata-OFL.txt` |
| `IBMPlexSans.woff2` | IBM Plex Sans 3.201 (IBM) | `wght` 100–700, `wdth` зафиксирован на 100 | SIL OFL 1.1 — `IBMPlexSans-OFL.txt` |

Подключаются в `app/layout.tsx` через `next/font/local`; сборка сайта в сеть за
шрифтами не ходит (#125). Символы — латиница, кириллица, греческий, вьетнамский
и их расширения (объединение подмножеств, которые раздавал Google Fonts).

Файлы собраны из исходников `google/fonts` (коммит зафиксирован в скрипте) и
сверены с файлами, которые раздавал Google Fonts до перехода, — контуры и
ширины всех символов на весах 100–900 совпадают без единого расхождения.
Пересобрать (нужна сеть):

```bash
uv run --no-project --with fonttools --with brotli --with certifi \
    python apps/web/scripts/build_fonts.py [--verify <каталог с файлами Google>]
```

OFL разрешает встраивать и распространять шрифты вместе с сайтом; файлы
лицензий лежат рядом и должны оставаться рядом со шрифтами.
